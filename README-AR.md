# Builder Mobile — إضافة تطبيق iOS إلى مشروع ios-builder

هذه الحزمة تضيف تطبيق iPhone أصلياً يعمل كواجهة لإدارة بناء تطبيقات iOS عبر GitHub Actions. لا تستبدل أداة Go الحالية؛ بل تضيف طبقة تطبيق للهاتف تستفيد من نفس فكرة البناء على أجهزة macOS السحابية.

## ما الذي يفعله التطبيق؟

1. يتصل بحساب GitHub باستخدام Personal Access Token ويحفظه في iOS Keychain.
2. يعرض المستودعات التي يملك الحساب صلاحية الوصول إليها.
3. يضيف تلقائياً ملف `.github/workflows/ios-build-from-phone.yml` إلى المستودع المحدد.
4. يشغّل سير العمل على الفرع الافتراضي، ثم يعرض عمليات البناء الأخيرة.
5. ينزّل ملف artifact بصيغة ZIP ويحفظه للمشاركة أو الحفظ في تطبيق Files.

## إضافة الملفات إلى المستودع الأصلي

فك ضغط `ios-builder-mobile-overlay.zip` داخل جذر مستودع `xte1/ios-builder` مع دمج المجلدات، بحيث ينتج:

- `ios-app/BuilderMobile.xcodeproj/`
- `ios-app/BuilderMobile/`
- `.github/workflows/ios-app-build.yml`

لا تحذف ملفات Go الحالية أو سير العمل الموجود.

## بناء التطبيق عبر GitHub Actions

بعد رفع التغييرات إلى فرع `main`، افتح GitHub → Actions → **Build Builder Mobile App** → Run workflow. سيُنتج سير العمل artifact باسم `BuilderMobile-unsigned-IPA`.

## صلاحيات GitHub المطلوبة داخل التطبيق

أنشئ Fine-grained Personal Access Token للمستودعات التي تريد البناء منها بهذه الصلاحيات:

- Metadata: Read
- Contents: Read and write
- Actions: Read and write
- Workflows: Read and write

لا ترسل الرمز إلى أي شخص؛ التطبيق يخزّنه محلياً في Keychain.

## حدود النسخة الحالية

- هذه الواجهة تدير بناء مشاريع موجودة في مستودعات GitHub؛ لا توفر محرر Swift أو واجهة تصميم تطبيقات كاملة داخل الهاتف.
- سير العمل ينشئ IPA غير موقّع. لا يمكن تثبيته مباشرةً على iPhone ولا إرساله إلى TestFlight قبل توقيعه بشهادة Apple وملف Provisioning Profile صالحين.
- تنزيل artifact يتم كملف ZIP؛ فك ضغطه في تطبيق Files لاستخراج ملف IPA.
- تم إعداد مسار البناء للمشاريع الشائعة: Swift/Xcode وFlutter وReact Native وExpo. قد تحتاج بعض المشاريع ذات الإعدادات المخصصة أو امتدادات التطبيقات إلى ضبط Xcode Scheme أو إعدادات توقيع إضافية.

## بناء محلي على Mac

افتح `ios-app/BuilderMobile.xcodeproj` في Xcode، اختر Target BuilderMobile، أضف Apple Development Team إلى Signing & Capabilities، ثم نفّذ Build على جهاز أو Simulator.


## ما الجديد في هذا التحديث

- **تصنيف المشاريع**: شريط علوي (الكل / تطبيقات / سورسات / مواقع). اضغط مطولاً على أي مشروع أو اسحبه لليمين لتمييزه، أو غيّر التصنيف من صفحة المشروع.
- **حذف المشروع** (يتطلب كتابة اسمه للتأكيد) من صفحة المشروع أو بالسحب في القائمة.
- **إدارة الملفات**: تحديد متعدد، تنزيل ملف/مجلد/عدة ملفات/المشروع كاملاً (ZIP)، وحذف فردي أو جماعي أو حذف كل الملفات (commit واحد).
- **سجل البناء الكامل**: كل العمليات (وليس آخر واحدة فقط) مع المهام والخطوات، واستخراج الأخطاء من السجل، وتنزيل log أو الأخطاء فقط، وزر «إصلاح الأخطاء بالذكاء الاصطناعي».
- **الذكاء الاصطناعي**: مزوّد مجاني للبرمجة (Qwen3 Coder عبر OpenRouter بمفتاح مجاني) أو Claude بمفتاح API، لإنشاء المشاريع وتعديل الملفات وقراءة سجل البناء وإصلاحه، مع رفع الصور والملفات.
- **التوقيع والتنزيل**: تنزيل ملفات IPA المبنية، وإضافة شهادات (.p12 + .mobileprovision) وتوقيع التطبيق على GitHub Actions.
- **الإعدادات ومعلومات المطور.**

## ملاحظات مهمة

- **تسجيل الدخول بحساب Claude Code غير ممكن**: تمنع Anthropic تطبيقات الأطراف الثالثة من استخدام تسجيل دخول Claude.ai أو اشتراكات Pro/Max. لذلك يعمل الذكاء الاصطناعي بمفتاح **Anthropic API** (console.anthropic.com) المحفوظ في Keychain.
- **التوقيع** يتم على خادم macOS في GitHub: تُشفَّر الشهادة داخل التطبيق (libsodium sealed box) وتُرفع كأسرار `SIGN_P12_BASE64` و`SIGN_P12_PASSWORD` و`SIGN_PROFILE_BASE64`. يلزم تفعيل صلاحية **Secrets: Read and write** في الرمز. التطبيقات ذات الإضافات (extensions) تحتاج Profiles منفصلة.
- مشاريع iOS التي ينشئها الذكاء الاصطناعي تستخدم `project.yml` (XcodeGen)؛ يولّد سير البناء ملف .xcodeproj تلقائياً.
- لم أتمكن من تشغيل مترجم Swift هنا، لذا ابنِ المشروع (Actions ← Build Builder Mobile App) وأرسل لي أي خطأ ترجمة لأصلحه.

## تحديثات إضافية

- إنشاء مشروع «تطبيق» يطلب الاسم والمعرّف (مثل `com.azawy.icerf`) وصورة الأيقونة، ثم يُنشئ مشروع SwiftUI جاهزاً للبناء (`project.yml` + الأيقونة).
- بعد اكتمال البناء أو التوقيع يظهر زر «مشاركة ملف IPA» لإرساله لأي شخص.
- تحسين شاشة الذكاء الاصطناعي: زر رجوع وإخفاء الكيبورد.
